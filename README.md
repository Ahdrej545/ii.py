# Цифровая Вечность

Локальная симуляция с картой, потребностями, отношениями, памятью и объяснением решений. Работает без API и сторонних Python-библиотек.

## Запуск

Нужен Python 3.10+ с Tkinter (компонент Tcl/Tk стандартного установщика Python для Windows). В терминале из папки репозитория:

```powershell
python app.py
```

Старый запуск `python "Искуственый мир.py"` тоже открывает окно. Начальное состояние — пауза. Нажмите «+1 час» или «Продолжить». Один шаг равен одному игровому часу. Скорость 1×, 2×, 5× задаёт примерно 1, 2, 5 шагов в секунду; сетевые запросы могут замедлить шаг. Пауза запрещает следующие шаги, начатый шаг завершается. `simulate_day()` выполняет 24 шага.

Нажмите имя на карте или выберите жителя в списке. Справа доступны личная цель и её прогресс, состояние, причины выбора, отношения с причинами и последние воспоминания. Карточка и лента имеют полосы прокрутки. «Новый мир» начинает демонстрацию заново. Автосохранения нет: перед закрытием, загрузкой или новым миром сохраните нужное состояние через «Сохранить…».

## Как работает память

Шкалы означают удовлетворённость: высокая сытость означает, что человек сыт. Сначала удовлетворяются критические потребности в еде и сне, затем общение, затем личная цель в рабочие часы, затем интересы. Еда, сон и разговор восстанавливают соответствующие шкалы.

Для свободных занятий место выбирается по сумме интереса, погоды и эмоциональных оценок памяти с затуханием 0.9 на запись. Для решений отбираются до 6 последних важных воспоминаний о целях/отношениях и до 6 остальных, чтобы бытовые записи не сразу вытесняли важное. Собеседник выбирается по сумме отношения и памяти о встречах. Положительный опыт привлекает, отрицательный отталкивает. Причина решения видна в карточке. В демонстрации уже есть несколько воспоминаний. Хранятся 50 воспоминаний и 100 событий. Старые записи «Ошибка ИИ» остаются в архиве, но исключаются из решений и диалогов.

## Цели на несколько дней и причины отношений

Начальные цели определяются характером: художник готовит выставку, философ укрепляет дружбу, исследователь работает над проектом. Проект и выставка требуют 12 этапов, не более 3 в день с 10:00 до 18:00. Потребности имеют приоритет: голодный или уставший житель сначала заботится о себе. Для дружбы нужны тёплые встречи в 3 разных дня; повторные встречи в тот же день не увеличивают прогресс цели.

На подготовке выставки житель просит помощь. Выбирает помощника по отношениям и памяти. Помощник отказывает, если голоден, устал или уже выполнил два этапа собственного исследовательского проекта за день. Отказ снижает отношение на 0.12, запоминается и исключает этого помощника из новых просьб на два дня. Следующая просьба возможна через сутки; житель ищет другого. Помощь повышает отношение на 0.18 и позволяет завершить выставку без дополнительного ожидания. Если помощников нет, после пяти дней житель пробует закончить самостоятельно.

Разговор после отказа или ссоры при усталости одного из участников приводит к ссоре (−0.15). Отдохнувшие участники обсуждают разногласие и мирятся (+0.16). Спокойная беседа даёт +0.04. Повторный разговор той же пары в течение 8 часов не меняет отношения повторно. Все изменения двусторонние, ограничены диапазоном −1…+1 и имеют записанную причину; случайных скачков отношений нет. Карточка показывает последние 3 причины по каждому знакомому; сохранение хранит до 12.

Срок цели — 7 игровых дней. Успех и неудача остаются в памяти. Через сутки после завершения выбирается следующая цель; после неудачи житель повторяет попытку с меньшим объёмом работы на основании последних неудач. Хранятся 5 прошлых целей. Лента показывает начало цели, ежедневный этап работы, исход и социальные события, а не каждую еду или отдых. Это правила возникновения историй: конкретная последовательность помощи и отказов не заскриптована. Для наблюдения запустите мир на скорости 5× на несколько игровых дней. Без API доступны все механики.

## DeepSeek — по желанию

Без ключа локальные реплики ссылаются на воспоминания. Для включения внешнего генератора диалогов перед запуском:

```powershell
$env:DEEPSEEK_API_KEY = "ваш-ключ"
python app.py
```

Ключ не записывается в сохранение. В API отправляются имена, характеры, цели, отношения и последние воспоминания обоих участников. Правила решений и причины социальных событий остаются локальными; генератор получает уже определённый исход. При сетевой ошибке, неверном ключе или некорректном ответе используется локальная беседа; уведомление появляется внизу. Запрос выполняется в отдельном потоке с таймаутом 8 секунд. Интернет и баланс DeepSeek нужны только для этого режима.

## Сохранения

«Загрузить…» читает исходный `digital_immortality_save.json`, формат v2 и новый v3 с целями и историей причин. При загрузке старого мира цели начинаются с его текущей даты, а причины старых оценок отношений не придумываются. Исходный файл автоматически не загружается и не изменяется; интерфейс запрещает сохранять поверх него. Выберите другое имя, например `world_save.json`.

Пропущенные обратные отношения восстанавливаются нейтральными. Старые воспоминания о кафе и встречах преобразуются в структурированные записи. Новый формат сохраняет время ISO, потребности, отношения, состояние, причины и память. Запись идёт через временный файл с заменой. Старые числовые даты читаются по локальному часовому поясу, как в прежнем коде; новые даты — игровое время без часового пояса.

## Проверки

```powershell
python -m unittest -v
```

16 проверок: еда/сон, час/сутки, влияние памяти на выбор места и собеседника, контекст диалога, двусторонние отношения, сохранение/загрузка и импорт исходного JSON без изменения, отказ API, 500 шагов с контролем границ; многодневное завершение цели, выбор другого помощника после отказа и загрузки, условия ссоры/примирения и интервал встреч, дружба в разные дни, неудача и уменьшение объёма новой попытки, выставка одинокого жителя, совместимость v2/v3 и ограничение объёма причин/событий за 20 дней.

Ограничения: это модель с простыми правилами, а не сознание или перенос личности. Пока есть три типа целей и одинаковые правила изменения отношений для всех. Карта схематична, встречи мгновенно перемещают собеседника. Память короткая, локальные диалоги шаблонные. Погода случайна: состояние генератора случайности не сохраняется. Добавление жителей доступно через Python API, редактора жителей в окне пока нет. Реальный DeepSeek не проверяется без пользовательского ключа; сгенерированный текст иногда может неточно описывать локальный исход.
