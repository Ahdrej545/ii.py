# Цифровая Вечность

Локальная симуляция с картой, потребностями, отношениями, памятью и объяснением решений. Работает без API и сторонних Python-библиотек.

## Запуск

Нужен Python 3.10+ с Tkinter (компонент Tcl/Tk стандартного установщика Python для Windows). В терминале из папки репозитория:

```powershell
python app.py
```

Старый запуск `python "Искуственый мир.py"` тоже открывает окно. Начальное состояние — пауза. Нажмите «+1 час» или «Продолжить». Один шаг равен одному игровому часу. Скорость 1×, 2×, 5× задаёт примерно 1, 2, 5 шагов в секунду; сетевые запросы могут замедлить шаг. Пауза запрещает следующие шаги, начатый шаг завершается. `simulate_day()` выполняет 24 шага.

Нажмите имя на карте или выберите жителя в списке. Справа доступны состояние, причины выбора, отношения и последние воспоминания. Карточка и лента прокручиваются. «Новый мир» начинает демонстрацию заново. Автосохранения нет: перед закрытием, загрузкой или новым миром сохраните нужное состояние через «Сохранить…».

## Как работает память

Шкалы означают удовлетворённость: высокая сытость означает, что человек сыт. Сначала удовлетворяются критические потребности в еде и сне, затем общение, затем интересы. Еда, сон и разговор восстанавливают соответствующие шкалы.

Место выбирается по сумме интереса, погоды и эмоциональных оценок последних 12 полезных воспоминаний с затуханием 0.9 на запись. Собеседник выбирается по сумме отношения и памяти о встречах. Положительный опыт привлекает, отрицательный отталкивает. Причина решения видна в карточке. В демонстрации уже есть несколько воспоминаний. Хранятся 50 воспоминаний и 100 событий. Старые записи «Ошибка ИИ» остаются в архиве, но исключаются из решений и диалогов.

## DeepSeek — по желанию

Без ключа локальные реплики ссылаются на воспоминания. Для включения внешнего генератора диалогов перед запуском:

```powershell
$env:DEEPSEEK_API_KEY = "ваш-ключ"
python app.py
```

Ключ не записывается в сохранение. В API отправляются имена, характеры, отношения и последние воспоминания обоих участников. Правила решений остаются локальными. При сетевой ошибке, неверном ключе или некорректном ответе используется локальная беседа; уведомление появляется внизу. Запрос выполняется в отдельном потоке с таймаутом 8 секунд. Интернет и баланс DeepSeek нужны только для этого режима.

## Сохранения

«Загрузить…» читает исходный `digital_immortality_save.json` и новый формат v2. Исходный файл автоматически не загружается и не изменяется; интерфейс запрещает сохранять поверх него. Выберите другое имя, например `world_save.json`.

Пропущенные обратные отношения восстанавливаются нейтральными. Старые воспоминания о кафе и встречах преобразуются в структурированные записи. Новый формат сохраняет время ISO, потребности, отношения, состояние, причины и память. Запись идёт через временный файл с заменой. Старые числовые даты читаются по локальному часовому поясу, как в прежнем коде; новые даты — игровое время без часового пояса.

## Проверки

```powershell
python -m unittest -v
```

Восемь проверок: еда/сон, час/сутки, влияние памяти на выбор места и собеседника, контекст диалога, двусторонние отношения, сохранение/загрузка и импорт исходного JSON без изменения, отказ API, 500 шагов с контролем границ.

Ограничения: это модель с простыми правилами, а не сознание или перенос личности. Карта схематична, встречи мгновенно перемещают собеседника. Память короткая, локальные диалоги шаблонные. Случайные реакции и погода дают разные продолжения: состояние генератора случайности не сохраняется. Добавление жителей доступно через Python API, редактора жителей в окне пока нет. Реальный DeepSeek не проверяется без пользовательского ключа.
